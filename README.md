# Next Pizza 🍕

Интернет-магазин пиццы с доставкой, свёрстанный по макету Figma.

## Возможности

- 🍕 Каталог пицц с карточками и изображениями
- 🔍 Поиск, сортировка и фильтрация (по цене, категории, ингредиентам)
- 🛒 Корзина с изменением количества и пересчётом суммы
- 🧩 Конструктор пиццы: выбор размера, теста и дополнительных ингредиентов
- 👤 Авторизация по SMS-коду (демо)
- 💳 Страница оформления заказа с итоговой суммой (товары + налог + доставка)
- 💾 Сохранение корзины в localStorage

## Технологии

- HTML5
- CSS3 (адаптивная вёрстка)
- Vanilla JavaScript (без фреймворков и сборщиков)

## Запуск

Просто откройте `index.html` в браузере или разверните на любом статическом хостинге.
